# PDV Plano B: versões para instalar

Este repositório guarda **só os instaladores** do PDV Plano B (caixa para Windows), publicados como *Releases*.
O código fica no repositório privado `pdv-planob`.

- O PDV instalado nas lojas consulta a última release daqui e se atualiza sozinho (instala ao fechar o sistema).
- Para instalar num caixa novo: baixe o `PDV-PlanoB-<versão>-x64.exe` da release mais recente e execute.
- Não apague nem edite os arquivos das releases (`latest.yml`, `.exe`, `.blockmap`): o atualizador depende deles.
